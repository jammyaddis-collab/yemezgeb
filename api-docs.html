Authentication

Register returns a JWT immediately. Send it as Authorization: Bearer <token> on every protected call. Tokens expire after 7 days. Roles: client, engineer, contractor, admin. Engineer storefronts stay inactive until an admin sets verified=1.

# Login once, reuse the token everywhere
TOKEN=$(curl -s -X POST http://localhost:3000/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"sara@example.com","password":"Demo1234!"}' | python3 -c "import json,sys;print(json.load(sys.stdin)['token'])")

Errors & status codes

StatusMeaningExample body
400Validation failed{"error":"deadline must be YYYY-MM-DD"}
401Missing / invalid token{"error":"Login required"}
403Role not allowed, or unverified engineer{"error":"Forbidden for role: client"}
404Resource not found (or not yours){"error":"Project not found"}
409Email already registered{"error":"Email already registered"}

All errors share the shape {"error": "…"}. Unknown API paths return 404 with the same shape; unknown pages return the homepage.

POST/api/auth/register

Create an account. Fields: name, email, password (≥8 chars), role (client default, engineer, contractor), license_no (required for engineers).

# Request
curl -s -X POST http://localhost:3000/api/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"name":"Sara Bekele","email":"sara@example.com","password":"Demo1234!","role":"client"}'

# Response 201
{ "token": "eyJhbGciOiJIUzI1NiIs…", "user": { "id": 4, "name": "Sara Bekele", "role": "client", "verified": 1 } }

POST/api/auth/login

Exchange email + password for a JWT. Returns user with id, name, role, verified.

# Response 200 (wrong credentials → 401 {"error":"Wrong email or password"})
{ "token": "eyJhbGciOiJIUzI1NiIs…", "user": { "id": 2, "name": "Ato Dawit Kassa", "role": "engineer", "verified": 1 } }

GET/api/auth/me🔑 JWT

Current user profile: id, name, email, role, verified, license_no.

curl -s http://localhost:3000/api/auth/me -H "Authorization: Bearer $TOKEN"

GET/api/boq/projects🔑 JWT

List the logged-in user's BoQ projects, newest first. Each: id, user_id, name, currency ("ETB"), created_at.

# Response 200
[ { "id": 1, "user_id": 4, "name": "G+1 Residence — Bole, Addis Ababa", "currency": "ETB", "created_at": "2026-10-21 14:51:08" } ]

POST/api/boq/projects🔑 JWT

Create a project. Body: { "name": "…" } (required).

curl -s -X POST http://localhost:3000/api/boq/projects \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"name":"Curl Test Villa"}'

# Response 201
{ "id": 2, "user_id": 4, "name": "Curl Test Villa", "currency": "ETB", "created_at": "2026-10-21 14:51:19" }

GET/api/boq/projects/:id/items🔑 JWT

Project + all line items (owner only — other users' projects return 404). Item fields: trade, description, unit, qty, rate.

# Response 200
{ "project": { "id": 2, "name": "Curl Test Villa", "currency": "ETB", "created_at": "…" },
  "items": [ { "id": 6, "project_id": 2, "trade": "2 — Substructure", "description": "Test footing", "unit": "m³", "qty": 10, "rate": 1000 } ] }

POST/api/boq/projects/:id/items🔑 JWT

Add a line item. Body: trade*, description*, unit (default No.), qty*, rate* — numbers ≥ 0.

curl -s -X POST http://localhost:3000/api/boq/projects/2/items \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"trade":"2 — Substructure","description":"Test footing","unit":"m³","qty":10,"rate":1000}'

# Response 201
{ "id": 6, "project_id": 2, "trade": "2 — Substructure", "description": "Test footing", "unit": "m³", "qty": 10, "rate": 1000 }

DELETE/api/boq/items/:id🔑 JWT

Delete a line item the user owns.

curl -s -X DELETE http://localhost:3000/api/boq/items/6 -H "Authorization: Bearer $TOKEN"
# Response 200
{ "ok": true }

GET/api/tenders

    "region": "Oromia", "trade": "Road", "size": "Br 10M–50M", "deadline": "2026-11-02",
    "type": "Public", "bid_doc_fee": "Br 380,000", "created_by": null, "created_by_name": null, "created_at": "…" } ]

GET/api/tenders/:id

Public. Single tender; 404 if the id doesn't exist.

curl -s http://localhost:3000/api/tenders/1

POST/api/tendersadmin · contractor

Publish a tender. Body: title*, org*, region*, trade*, deadline* (YYYY-MM-DD), optional size, type (Public default), bid_doc_fee (default Br 0).

curl -s -X POST http://localhost:3000/api/tenders \
  -H "Authorization: Bearer $ADMIN_TOKEN" -H 'Content-Type: application/json' \
  -d '{"title":"Curl Test Tender","org":"Test Org","region":"Addis Ababa","trade":"Building","size":"Under Br 10M","deadline":"2026-12-01"}'

# Response 201 — full tender object with new id

GET/api/legal

Public. Optional ?q= searches titles, Amharic titles, categories and English summaries (LIKE match). Fields include title, title_am, category, language, source, summary_en, summary_am.

    "category": "Seismic Standard", "language": "EN", "source": "Ethiopian Building Code Standard",
    "summary_en": "Seismic zoning and design loads for structures…", "summary_am": "…" } ]

GET/api/legal/:id

POST/api/legaladmin

Add a document. Body: title*, category*, source*; optional title_am, language (default EN), summary_en, summary_am.

curl -s -X POST http://localhost:3000/api/legal \
  -H "Authorization: Bearer $ADMIN_TOKEN" -H 'Content-Type: application/json' \

GET/api/listings

Public. Filters: plot (exact), style (exact), rooms (min rooms), budget (Under Br 5,000 / Br 5,000–15,000 / Br 15,000+). Sorted by rating desc. Includes designer_name and verified.

curl -s "http://localhost:3000/api/listings?budget=Under%20Br%205,000"

    "rating": 4.7, "verified_designer": 1, "designer_name": "Ato Dawit Kassa", "verified": 1 } ]

POST/api/listingsengineer · verified

Create a storefront listing. Body: title*, description*, price* (positive ETB); optional plot_size, rooms, style, file_types (default PDF). Unverified engineers get 403.

curl -s -X POST http://localhost:3000/api/listings \
  -H "Authorization: Bearer $ENGINEER_TOKEN" -H 'Content-Type: application/json' \
  -d '{"title":"Duplex Plan","description":"4 bedrooms…","price":12000,"style":"Modern","rooms":4}'
# Response 201 — listing object

POST/api/ordersclient · contractor

Buy a design → funds held in escrow. Body: listing_id*, method (one of Telebirr, CBE Birr, Chapa, Santim Pay, Bank Transfer — default Telebirr). Amount is copied from the listing.

curl -s -X POST http://localhost:3000/api/orders \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"listing_id":1,"method":"Telebirr"}'

# Response 201
{ "message": "Funds held in escrow. Files unlock after verification.",
  "order": { "id": 1, "listing_id": 1, "buyer_id": 4, "amount": 8500, "method": "Telebirr",
             "status": "escrow_held", "created_at": "…" } }

POST/api/orders/:id/deliverengineer · seller

Seller marks the drawing files as delivered → status files_delivered. Only the listing's own designer can call this.

curl -s -X POST http://localhost:3000/api/orders/1/deliver -H "Authorization: Bearer $ENGINEER_TOKEN"
# Response 200 — order with status "files_delivered"

POST/api/orders/:id/release🔑 JWT (buyer)

Buyer releases escrow after receiving files. 400 if status isn't files_delivered yet.

curl -s -X POST http://localhost:3000/api/orders/1/release -H "Authorization: Bearer $TOKEN"

# Response 200
{ "message": "Escrow released to designer", "order": { …, "status": "released" } }
